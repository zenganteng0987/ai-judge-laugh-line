[Make the AI Judge Laugh](https://make.fun/competitions/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
competition on make.fun.

## Run

```sh
node main.ts
```

It writes a single line (1–200 characters) to `/output/entry.txt`.
